# Fitness Tree Gym Website

A responsive React + Vite website for Fitness Tree Gym.

## How to Run Locally

1. **Install Node.js** from https://nodejs.org (version 18 or higher)

2. **Open a terminal** in this folder and run:

```bash
npm install
npm run dev
```

3. Open your browser and go to: **http://localhost:5173**

## Build for Production

```bash
npm run build
```

This creates a `dist/` folder you can upload to any web host.
